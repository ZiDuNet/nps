两个开关互不依赖：自动 CORS 控制浏览器是否允许跨域读取响应；兼容模式控制普通 HTTP 请求使用哪条转发链路。按需分别开启。

自动 CORS：否

开启后追加 Access-Control-Allow-Origin: *、允许方法和允许请求头，适合不同域名的前端调用 API。关闭后不追加这些响应头，浏览器按后端自己的 CORS 配置校验。它不会替后端处理 OPTIONS 预检；使用 Cookie 或凭据时，通配符 * 也不适用。

兼容模式：否

开启后普通 HTTP 请求使用标准反向代理链路，适合 SSE、流式响应、复杂 Header 等场景；关闭时使用更轻量的原始 HTTP 转发，普通请求开销更低。带 Upgrade: websocket 的请求会自动走标准反代，不需要为了 WebSocket 单独开启此项。
