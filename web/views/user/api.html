接口鉴权方式

管理员密钥使用时间戳签名：auth_key = MD5(密钥 + timestamp)，并把 timestamp 一并提交，时间差需在 20 秒内。用户 Token 使用 Bearer 头或 api_token 参数。

auth_key = md5(key + timestamp)
GET/POST /index/clientlist?auth_key=<签名>&timestamp=<unix 秒>
