# Country/region flags

These unmodified 4:3 SVGs are from `flag-icons@7.6.0`:
https://github.com/lipis/flag-icons/tree/v7.6.0

Only the 249 ISO country/region flags plus XK are included. They are loaded on
demand from the NPS origin; no runtime CDN or package manager is required.
The country-code allowlist in `nps-ip-region.js` must match this asset set.
