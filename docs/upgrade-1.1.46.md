# NPS 1.1.46 升级说明

本版本新增飞牛 fnOS 原生 NPC 客户端 FPK 包，并补齐服务端配置热更新、版本检查缓存和持久化 ID 回收。

## 主要变化

- 新增 `NPC-Pro` FPK 包（仅 NPC 客户端）：不监听网络端口，设置页通过飞牛统一网关挂在 `/app/NPC-Pro`，后端仅监听本地 Unix Socket 并复用飞牛登录态。内嵌设置页支持连接列表、快捷指令/手动配置二选一、直接编辑 `npc.conf`、查看并清空最近最多 500 条日志；保存后运行中 NPC 自动热重载。
- 支持同一台飞牛连接多个不同 VKey：每条连接独立 `npc.conf` 并由独立子进程运行。首次安装释放完整配置模板，升级 FPK 保留设备 `etc` 目录中的 `npc.conf`、手写规则和注释。
- 服务端配置保存支持部分运行时参数即时生效：允许端口、注册/登录/VKey 开关、验证码、限速/配额开关、连接历史保留数、流量落盘间隔、审计/连接日志路径等不再需要重启；监听端口、TLS、日志适配器、会话存储等仍需重启。
- 面板版本检查改为服务端每 6 小时统一查询并缓存，页面不再直连 GitHub。
- 删除最后一个客户端、隧道或 Host 后回收持久化 ID；流量计数器支持管理员重置并同步清理速率基线。

## 兼容性与迁移

- 不改变 Bridge 握手、NPC 业务协议、历史快捷命令或用量快照格式，旧 NPC、旧配置和业务 JSON 无需手工迁移。
- FPK 与 Docker 客户端不接受服务端远程自更新，请从飞牛应用中心安装新版；普通 CLI、系统服务和 GUI 的更新行为不变。
- 升级前仍建议备份整个 `conf` 目录。

## 飞牛 FPK 首版验证

FPK 构建成功不等于真机兼容性完成。首次发布前需在实际 fnOS 设备上验证：安装向导、内嵌设置页的网关访问与登录态、表单联动、直接编辑 `npc.conf`、多 VKey 启停、升级保留配置和日志清理。
