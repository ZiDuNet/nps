# 更新日志

## v1.1.39（2026-10-30）

- 用户管理和客户端列表改为用户名主行、备注次行显示，客户端备注和出口地址采用单行省略并保留完整悬浮提示，客户端备注与所属用户内容统一居中；管理员用户/客户端筛选统一使用「备注（账号）」和「客户端备注（ID）」，隧道与域名规则列表支持用户到客户端的联动筛选，同时保留单独筛选。
- 客户端列表默认显示入口、出口流量，表头拆分显示公网到内网、内网到公网方向；域名反代自定义域名增加独立来源标签，入口按钮改为保留外链图标的“HTTP / HTTPS”；客户端列按“客户端备注 · ID”“所属用户备注 · ID”两行展示，超长内容自动省略并可悬浮查看全文。
- 隧道列表的目标地址按 IP/端口分行展示，只有端口时仅显示端口；访问地址不再整行跳转，提供复制和 TCP HTTP 尝试按钮；TCP 当前连接列默认收起，仍可通过列表列设置和展开详情查看。

## v1.1.38

- 客户端连接日志补充 Bridge 主连接、子通道、握手与认证失败、隧道和域名代理会话的服务端地址、公网来源、客户端公网/内网地址及来源、客户端版本、Bridge 通道、握手阶段和账号到期信息。
- 管理操作审计和连接日志的展开详情统一为紧凑的终端式原始 JSON 视图；普通用户仍只能查看所属客户端记录，日志不保存凭据或业务正文。
- 所有列表页工具栏统一为左侧业务操作、右侧「搜索、筛选、列、刷新」，登录封禁和 IP 登记迁移到公共表格组件，域名反代补齐列菜单。
- 登录封禁支持搜索、筛选和分页；服务端配置分类保存只校验当前页面字段，修复专项配置误拦通用页保存，并优化响应式配置卡片布局。
- 不改变 Bridge 协议、快捷命令、JSON 持久化或 `/api/v1` 既有字段，NPS 与 NPC 无需同步升级。

## v1.1.37

- 新增 TCP、TCP + TLS、KCP、WS、WSS、QUIC 和 HTTP/3 共用入口的多 Bridge 连接命令，以及兼容历史 v1 的 v2 快捷命令；NPC CLI、GUI 和系统服务支持完整协议参数。
- 客户端列表显示实际连接协议，仪表盘展示所有实际启用的 Bridge 入口；同一 VKey 可使用不同协议并行连接且系统服务名互不覆盖。
- 新增独立「证书设置」页面，集中维护 Bridge 证书、平台泛域名、HTTPS/ACME、管理面板 HTTPS 和 IP 登记 HTTPS。
- 自定义域名只允许上传或粘贴证书，历史服务器路径只读兼容；Web 与 `/api/v1/hosts` 使用相同校验规则，查询不返回证书和私钥路径。
- 用户管理新增同一用户全部客户端共享的最大并发连接数、上行带宽和下行带宽；`0` 表示不限，P2P 直连不计入。
- 「系统 → 全局参数」新增「用户注册」Tab，集中维护注册入口、默认权益、限频、邮箱验证和 SMTP；新注册账号默认不限配额、带宽和连接数，并永久有效。
- 管理员 `/api/v1/users/register` 支持 `max_conn`、`upload_limit`、`download_limit` 覆盖默认值。
- 修复用户共享并发额度达到上限后仍可能放行新连接的问题。
- 新增客户端连接日志和 `GET/POST /api/v1/audit/connections`；普通用户只能查看所属客户端记录，日志不保存凭据或业务正文。
- 修复 `audit_log_path` 留空仍写入 `audit.log` 的问题，空值现在会关闭独立操作审计文件。
- 删除旧版 IP 白名单授权页面、代理链路和 `/auth/ipwhiteauth`、`/api/v1/ipwhiteauth` 接口，只保留新版 IP 登记机制。

## v1.1.36

- 自助注册改为独立用户体系，支持后台设置默认客户端配额、隧道配额和有效天数；`0` 分别表示不限或永久。
- 注册增加图片验证码、频率限制、单 IP 成功注册上限和可选邮箱验证码。
- 新增管理员注册 API `/api/v1/users/register`，支持 `expire_days`、`expire_time`、`max_client` 和 `max_tunnel`。
- 用户邮箱全局唯一，并修复并发注册可能绕过唯一性检查的问题。
- 注册页仅在配额为 `0` 时标注“不限”，非零客户端或隧道配额只显示实际数量。
- 服务端配置页新增配置摘要、字段搜索和完整源码视图；修复敏感项与私钥路径回显，源码保存增加语法、配置关系与并发冲突校验。
- 普通用户可管理自己客户端下的 IP 登记，不能访问其他用户或公共登记桶；现有管理员能力保持不变。
- 「系统 → 全局参数」的「全局参数」Tab 支持远程 URL、`conf` HTML 文件和直接粘贴 HTML，修改后无需重启或重新编译面板。
- Geo 数据路径留空时自动使用 `conf/geoip.dat` 与 `conf/geosite.dat`，支持文件热更新。
- 现有 `nps.conf` 自动补齐注册配置，SMTP 默认关闭；Bridge 协议、NPC 版本和既有接口保持兼容。

## v1.1.35

- 修复普通用户访问 `/user/api` 时页面白屏的问题；普通用户可打开 API 接入页并管理个人 Token，用户管理、全局参数和管理员密钥接口仍仅限管理员访问。
- 新增非管理员页面与动作白名单回归测试，并在 README 首页补充登录、IP 登记、客户端编辑和域名反代编辑截图。

## v1.1.34

- 域名反代列表移除「认证」列，改用访问入口前的锁图标表示 Basic 认证状态；列表数据只返回状态、不回传凭据。
- 域名反代与 TCP 隧道展开详情统一为紧凑卡片布局；IP 名单用标签展示，Basic 密码只显示「已设置/未设置」。
- 全局参数「平台泛域名」输入区单列排版并限制输入宽度，证书信息布局更整齐。
- 修复域名反代表单在健康检查未启用时保存被浏览器校验拦截的问题。

## v1.1.33

- 管理面板删除客户端时向在线 NPC 下发「注册已删除」指令；新版 NPC 关闭该连接并停止重连，旧版 NPC 保持原行为。
- NPC 以系统服务运行时只停止被删除的连接，进程内最后一条连接结束时才自动停止本机 NPC 服务，保留服务注册，不卸载。
- 修复 NPC 数据通道关闭时的阻塞与文件描述符泄漏，删除客户端后数据通道立即完整释放。
- NPS/NPC Docker 镜像补齐 CA 证书，修复 Geo 在线更新与版本检测的证书校验失败。
- 「API 接入」页文档链接改到官方文档站并修复管理员密钥生成按钮；登录页、主布局和错误页统一显示浏览器标签页图标。

## v1.1.32

- 新增统一对外 API `/api/v1`，覆盖客户端、隧道、域名反代、用户、全局参数、Geo、IP 登记、审计、状态与拓扑。
- 所有响应统一返回 `status`、`code`、`msg`、`request_id`，失败额外返回 `error_code`；列表支持有界分页。
- 管理员使用 `auth_key + timestamp` 签名，普通用户使用按授权范围生效的 Bearer Token；`/api/v1` 不依赖浏览器 Session。
- 旧 `/auth/*`、`/client/*`、`/index/*`、`/user/*`、`/global/*` 路径和返回格式保持不变。
- 开发期间短暂新增但从未正式发布的 `/v1/auth/*` 已移除，统一收口到 `/api/v1`。

## v1.1.31

- Secret/P2P 的 `target_type` 真正支持 `tcp`、`udp`、`all`，UDP 数据报边界完整保留；P2P 访客默认支持 Secret 回退。
- 隧道新增最大连接数与总流量配额；域名反代证书支持路径、上传、粘贴与校验。
- 新增可复用 Token 的「API 接入」页、Geo 数据在线更新、更完整的仪表盘配置信息。
- 普通用户可设置自己名下客户端的独立到期时间；客户端版本号点击后可直接检测并下发升级。
- 管理面板移除 ZUI、全面迁移 Bootstrap 5.3.3，表单分组联动、列表详情紧凑化，工具栏与操作交互统一。
- 修复公共 vkey 配置文件模式注册卡死，升级 `quic-go` 修复 P2P 直连 QUIC 握手 panic。

## v1.1.30

- NPC 自定义 DNS、HTTP/HTTPS 与 SOCKS4/4a/5 出站代理、`ALL_PROXY`/`NO_PROXY` 环境代理现在实际生效。
- `local_ip`/`local_ip_forward` 覆盖 TCP、UDP、SOCKS5 UDP、KCP 和 QUIC 的出站绑定，并保持私网目标的默认路由。
- NPC 支持多服务端并行连接和多配置文件启动；管理员可在“登录封禁”页面清理临时登录保护记录。
- 直接启动的 NPC 可用 `-disable_remote_update=true` 禁止服务端升级指令，并支持 `npc update-force` 重新安装同版本正式包。
- 配置文件和 Docker 文档补齐，旧客户端与旧配置继续兼容。
- SOCKS5 UDP 使用共享 UDP 会话注册，补齐多来源绑定、队列保护、空闲/断线回收、目标 ACL 与大报文支持。
- 隧道列表合并配置、监听、客户端状态并优化表头提示与窄屏布局。

## v1.1.29

- 新增 Web 隧道与域名规则的后端健康检查配置，并按 NPC 版本自动选择兼容的控制消息。
- 新增规则级上行/下行限速、API 访问地址与速率字段，旧数据按不限速兼容。
- HTTP 正向代理与 SOCKS5 统一为混合代理；旧规则兼容，编辑时可迁移。
- 新增服务端 `nps.conf` 后台维护页，支持分组配置、敏感字段脱敏、可选键移除和重启提示。
- 新增 TCP、KCP、WebSocket/WSS 和 QUIC Bridge 传输入口；QUIC 使用独立 UDP 端口，不是浏览器 HTTP/3 Host 反代。
- 服务端启动时自动补齐缺失配置，保留既有值、注释、自定义字段和旧字段，支持原子写回。
- 管理面板继续按管理员、普通用户和客户端主体隔离资源；实时调试、审计、IP 登记和客户端升级沿用同一权限边界。
