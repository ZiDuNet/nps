# NPS 1.1.47 升级说明

本版本仅修复飞牛（fnOS）NPC 客户端的两个问题：纯连接模式断线后不自动重连，以及内嵌设置页日志顺序。

## 主要变化

- 修复飞牛纯连接模式（`npc.conf` 仅含 `[common]`、没有本地隧道规则）断线后不自动重连的问题。此前 `WORK_MAIN` 断开后子进程会阻塞等待配置变更而非退出，管理进程卡在 `cmd.Wait()`，无法按 5 秒重建连接。现在按 `auto_reconnection` 决定：开启时子进程退出交由管理进程自动重连，关闭时保持等待配置变更。
- 飞牛内嵌设置页的日志视图改为最新在前显示，刷新后最新事件位于顶部。

## 兼容性与迁移

- 不改变 Bridge 握手、NPC 业务协议、历史快捷命令或配置格式，旧 NPC、旧配置和业务 JSON 无需手工迁移。
- 本次仅影响飞牛 FPK 客户端，不影响服务端、普通 CLI、系统服务和 GUI 客户端。
- 升级前仍建议备份整个 `conf` 目录。
