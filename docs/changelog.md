# 更新日志

## v1.1.37 (2026-10-29)

- 新增 TCP、TCP + TLS、KCP、WS、WSS、QUIC 和 HTTP/3 共用入口的多 Bridge 命令展示，并引入兼容历史 v1 的 v2 快捷命令；NPC CLI、GUI 和系统服务完整支持协议、Path、ALPN、SNI 与证书指纹。
- 新增「证书设置」页面，集中维护 Bridge 证书、平台泛域名、HTTPS/ACME、管理面板 HTTPS 和 IP 登记 HTTPS，并显示配置证书与运行证书状态。
- 自定义域名的证书录入收敛为“上传”和“粘贴”；历史路径证书只读兼容并继续生效，平台泛域名与 Bridge 证书仍由管理员使用路径、上传或粘贴维护。
- 自定义证书必须先校验有效性、私钥匹配和域名覆盖才能保存，保存后持续显示证书来源、文件名、有效期、SAN、主题、颁发者和指纹等详情。
- 新增用户级最大并发连接数、共享上行带宽和共享下行带宽；同一用户全部客户端使用一组额度，`0` 表示不限，P2P 直连不计入。
- 「全局参数」新增「用户注册」Tab，集中维护注册入口、新账号默认权益、注册限频、邮箱验证和 SMTP；新注册默认值全部为不限制/永久有效。
- 管理员 `POST /api/v1/users/register` 支持显式覆盖 `max_conn`、`upload_limit`、`download_limit`，省略时读取对应注册默认值。
- 修复用户连接额度达到上限后仍继续放行的问题；并发额度按用户原子共享。
- 彻底移除旧版 IP 授权页面、代理链路、客户端模型字段和 `/auth/ipwhiteauth`、`/api/v1/ipwhiteauth` 接口，只保留新版“仅允许已登记 IP”机制。
- 新增公开接口 `POST /api/v1/ip-register`；登记密钥只从 JSON 或表单请求体读取，访问 IP 由服务端按可信代理配置识别，客户端不能自行提交 IP。
- 修复域名反代新增和编辑页上传、粘贴证书时前端提交字段与后端读取字段不一致的问题；现可正常写入 `conf/certs/host_<ID>.pem/.key`。平台泛域名页面也会明确提示：未被主机引用时可更名或删除，已被引用时仅锁定名称，证书仍可更新。
- `/api/v1/hosts` 的新增、修改接口与 Web 表单统一证书规则：自定义域名只接受上传或粘贴，拒绝新服务器路径；历史路径仅可原样保留，查询不返回证书和私钥路径。
- 修复同一 VKey 的不同协议会话互相覆盖、HTTP/3 错误复用浏览器证书、无效 HTTP/3 入口仍生成命令以及退出活动连接计数等问题。

## v1.1.36 (2026-10-29)

- 自助注册改为创建独立用户并写入 `users.json`，支持后台配置默认客户端数、默认隧道数和默认有效天数；`0` 继续表示不限制，有效期 `0` 表示永久。
- 注册支持图片验证码、独立提交限频、单 IP 成功注册上限，以及可选的 SMTP 邮箱一次性验证码。
- 新增管理员 API `POST /api/v1/users/register`，可显式指定配额、`expire_days` 或绝对 `expire_time`；JSON 请求与查询参数中的管理员签名可同时使用。
- 用户邮箱不区分大小写且全局唯一；用户名、邮箱唯一性校验与写入已纳入同一互斥事务，避免并发注册产生重复账号。
- 注册页默认配额按实际配置值展示，仅在客户端或隧道配额为 `0` 时标注“不限”，避免非零配额被误解。
- 重构服务端配置页，增加配置摘要、字段搜索、分组展开和完整源码视图；修复私钥路径被误隐藏及 `auth_crypt_key`、ZeroSSL API 密钥等敏感项未使用密码控件的问题。源码保存支持语法校验、关键配置关系校验和并发修订冲突检测。
- 普通用户可打开「IP 登记」菜单，并管理自己客户端下的登记；管理员继续管理全部客户端和公共登记桶，后端按实时归属执行隔离。
- 新增可配置的「使用说明」页面：支持远程 URL、`conf` 下的 HTML 文件或直接粘贴 HTML；粘贴内容自动写入 `conf/qa.html`，文件缺失时页面仍可正常打开。
- 全局参数页按功能重新分组，服务端配置 Tab 补充图标；IP 登记、帮助文件读取和普通用户越权操作均增加回归测试。
- GeoIP/Geosite 路径留空时默认加载运行目录 `conf` 下的数据文件，文件出现或更新后自动重新加载。
- 不改变 Bridge 协议、现有 Web 接口或 `/api/v1` 调用；现有 `users.json` 无需迁移，NPS 与 NPC 无需同步升级。

## v1.1.33 (2026-10-26)

- 管理面板删除客户端时，NPS 会在断开前向在线的 NPC 下发「注册已删除」指令；新版 NPC 收到后关闭该客户端的控制连接与数据通道并停止重连，不再每 5 秒空转重试。旧版 NPC 忽略该指令，保持原有重连行为，兼容不变。
- 停用、到期和用户禁用仍使用普通断开方式，NPC 在状态恢复后可继续自动重连。
- NPC 以系统服务运行时收到删除指令，只停止被删除的那条连接；当该服务进程内的最后一条连接也因删除而结束时，才会自动停止本机 NPC 服务，但保留服务注册（Windows、Linux systemd/sysv/upstart、macOS launchd 等均处理），之后仍可用 npc 命令手动启动或停止。同一进程同时连接多个服务端时，删除其一不会影响其他连接。停止是尽力而为的后台动作，失败也不会阻塞 Web 端删除。
- 修复 NPC 数据通道（MUX）关闭时因查询 socket 缓冲大小把连接切到阻塞模式，导致连接迟迟无法真正断开、文件描述符泄漏的问题；现在删除客户端后数据通道会立即完整释放。
- NPS/NPC Docker 镜像补齐 CA 证书，修复 Geo 数据在线更新与版本检测报 `x509: certificate signed by unknown authority` 的问题。
- 「API 接入」页面的文档链接改为官方文档站 `https://zidunet.github.io/nps/api.html`，并修复管理员生成密钥按钮请求错误路径的问题。
- 登录页、管理面板主布局和错误页统一显示浏览器标签页图标（favicon）。

## v1.1.32 (2026-10-26)

- 新增统一对外 API `/api/v1`：覆盖客户端、隧道、域名反代、用户、全局参数、Geo、登录保护、IP 登记、审计、状态与拓扑，全部返回 `status`/`code`/`msg`/`error_code`/`request_id` 信封。
- `/api/v1` 只接受 API 凭据（管理员 `auth_key+timestamp` 或普通用户 `Bearer npsu_...`），不依赖浏览器 Session；普通用户资源继续按授权客户端过滤。
- 新增公开的 `/api/v1/time`、`/api/v1/authkey`、`/api/v1/ipwhiteauth` 与发现接口 `/api/v1`；旧 `/api/v1/ipwhiteauth` 已在后续版本删除，现使用 `/api/v1/ip-register`。
- 认证辅助接口统一收口到 `/api/v1`；未进入正式发布的 `/v1/auth/*` 已移除，旧 `/auth/*` 保持不变。
- 对外 API 支持 `application/json` 请求体，默认分页 `limit=20`、最大 `500`，支持 `page`/`page_size`。
- 旧 `/client/*`、`/index/*`、`/user/*`、`/global/*`、`/auth/*` 路径和返回格式保持不变，现有 NPC 与页面无需调整。

## v1.1.31 (2026-10-26)

- 移除管理面板的全局同源/Origin 校验：反代、混合 HTTP/HTTPS 和多端口部署不再出现「invalid request origin」误拦，POST 仅校验请求方法与登录/API 凭据。
- `GetClient`、`GetOneTunnel`、`GetHost` 单个查询接口同时返回旧 `code`/`data` 与标准 `status`/`msg` 字段；新增/复制隧道成功响应直接携带 `AccessHost`、`AccessAddr`、`AccessURL` 等访问地址，无需再回查列表。
- `addhost` 失败提示补齐标点，错误信息直接说明域名前缀冲突原因。
- Secret/P2P 的 `target_type`（`tcp`、`udp`、`all`）升级为真实转发能力；UDP 使用数据报帧协议保留报文边界，旧记录与旧客户端继续按 TCP 兼容。
- NPC 访客新增 `-fallback_secret`（默认开启），P2P 直连失败后自动回退 Secret 中继。
- 普通隧道新增隧道级最大连接数和总流量配额，0 表示不限，支持 Web 表单与 API。
- 域名反代证书统一支持路径、上传、粘贴三种录入方式并提供有效性校验，平台泛域名与自定义域名行为一致。
- 新增「系统 → API 接入」页面：Token 可再次查看和撤销；管理员拥有 `nps.conf` 密钥与网页密钥两套等价凭据，查看原文需验证登录密码。
- 全局参数支持查看 Geo 数据状态并在线更新，默认使用 `conf/geoip.dat` 和 `conf/geosite.dat`。
- 仪表盘补齐 Bridge 各入口端口、P2P 地址、IPv4/IPv6 出口地址、已登记 IP 数和最小安全握手版本等配置信息，并按卡片分组。
- 普通用户可设置自己名下客户端的独立到期时间，仍受所属用户有效期约束。
- 客户端版本号改为可点击入口，弹窗检测最新版本并下发远程升级。
- 管理面板移除 ZUI 并全面迁移 Bootstrap 5.3.3；表单按业务分组、高级项收起、字段联动，列表详情紧凑多列展示，工具栏与操作交互统一，减少整页刷新。
- 公共 vkey 注册生成 16 字符验证密钥，修复配置文件模式注册卡死；`quic-go` 升级至 v0.64.1，修复 Go 1.26 下 P2P 直连 QUIC 握手 panic。
