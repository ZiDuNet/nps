# 更新日志

## 未发布

- 新增统一对外 API `/api/v1`：覆盖客户端、隧道、域名反代、用户、全局参数、Geo、登录保护、IP 登记、审计、状态与拓扑，全部返回 `status`/`code`/`msg`/`error_code`/`request_id` 信封。
- `/api/v1` 只接受 API 凭据（管理员 `auth_key+timestamp` 或普通用户 `Bearer npsu_...`），不依赖浏览器 Session；普通用户资源继续按授权客户端过滤。
- 新增公开的 `/api/v1/time`、`/api/v1/authkey`、`/api/v1/ipwhiteauth` 与发现接口 `/api/v1`。
- 对外 API 支持 `application/json` 请求体，默认分页 `limit=20`、最大 `500`，支持 `page`/`page_size`。
- 旧 `/client/*`、`/index/*`、`/user/*`、`/global/*`、`/v1/auth/*` 路径和返回格式保持不变，现有 NPC 与页面无需调整。

## v1.1.31 (2026-10-26)

- 移除管理面板的全局同源/Origin 校验：反代、混合 HTTP/HTTPS 和多端口部署不再出现「invalid request origin」误拦，POST 仅校验请求方法与登录/API 凭据。
- 新增 `/v1/auth/time`、`/v1/auth/authkey`、`/v1/auth/ipwhiteauth` 标准信封接口，与旧 `/auth/*` 接口并存；旧路径和旧返回格式不变，登录页与既有集成无需调整。
- `GetClient`、`GetOneTunnel`、`GetHost` 单个查询接口同时返回旧 `code`/`data` 与标准 `status`/`msg` 字段；新增/复制隧道成功响应直接携带 `AccessHost`、`AccessAddr`、`AccessURL` 等访问地址，无需再回查列表。
- `addhost` 失败提示补齐标点，错误信息直接说明域名前缀冲突原因。
- Secret/P2P 的 `target_type`（`tcp`、`udp`、`all`）升级为真实转发能力；UDP 使用数据报帧协议保留报文边界，旧记录与旧客户端继续按 TCP 兼容。
- NPC 访客新增 `-fallback_secret`（默认开启），P2P 直连失败后自动回退 Secret 中继。
- 普通隧道新增隧道级最大连接数和总流量配额，0 表示不限，支持 Web 表单与 API。
- 域名反代证书统一支持路径、上传、粘贴三种录入方式并提供有效性校验，平台泛域名与自定义域名行为一致。
- 新增「系统 → API 接入」页面：Token 可再次查看和撤销；管理员拥有 `nps.conf` 密钥与网页密钥两套等价凭据，查看原文需验证登录密码。
- 全局参数支持查看 Geo 数据状态并在线更新，默认使用 `conf/geoip.dat` 和 `conf/geosite.dat`。
- 仪表盘补齐 Bridge 各入口端口、P2P 地址、IPv4/IPv6 出口地址、已登记 IP 数和最小安全握手版本等配置信息，并按卡片分组。
- 普通用户可设置自己名下客户端的独立到期时间，仍受所属用户有效期约束。
- 客户端版本号改为可点击入口，弹窗检测最新版本并下发远程升级。
- 管理面板移除 ZUI 并全面迁移 Bootstrap 5.3.3；表单按业务分组、高级项收起、字段联动，列表详情紧凑多列展示，工具栏与操作交互统一，减少整页刷新。
- 公共 vkey 注册生成 16 字符验证密钥，修复配置文件模式注册卡死；`quic-go` 升级至 v0.64.1，修复 Go 1.26 下 P2P 直连 QUIC 握手 panic。

## v1.1.30 (2026-10-25)

- NPS/NPC 配置文件和命令行支持自定义 DNS；多个 DNS 服务器会轮询并在失败时切换，未配置时保持系统解析器。
- NPC 出站 Bridge 代理支持 HTTP/HTTPS CONNECT、SOCKS4/4a、SOCKS5/SOCKS5H，以及 `ALL_PROXY`/`NO_PROXY` 环境变量。
- `local_ip` 与 `local_ip_forward` 现在实际作用于 TCP、UDP、SOCKS5 UDP、KCP、QUIC 和 P2P 相关出站连接；私网目标仍保持默认路由。
- 补齐 NPC Docker/配置文件说明，并继续兼容旧客户端与旧配置。
- NPC 命令行支持同时连接多个 NPS 服务端，配置文件模式支持多份配置并行运行；管理员可查看、解封和清理登录保护记录。
- 直接启动的 NPC 可用 `-disable_remote_update=true` 忽略服务端升级指令，并新增 `npc update-force` 重新安装同版本正式包。
- SOCKS5 UDP ASSOCIATE 使用共享 UDP 端口和会话注册，支持多来源绑定、队列保护、空闲/断线回收、目标 ACL 与大报文转发。
- 隧道列表把配置、监听、客户端状态合并为一组紧凑状态标记，表头支持悬浮显示完整名称，窄屏使用卡片布局避免横向滚动。

## v1.1.3 (2026-09-02)

### 发布与更新

- 正式 Release 改为在所有平台构建完成后统一上传，并附带 SHA-256 校验文件。
- CLI 与 GUI 更新器按规范语义版本下载并校验平台资产和 SHA-256，避免安装非正式构建。
- 补齐 Linux ARM 通用包和 Windows ARM64 CLI 包，macOS GUI 更新改为替换完整 `.app` 包。

### Bridge 协议与兼容性

- 增加 Bridge 握手超时保护、HTTP CONNECT 代理鉴权、SOCKS5 认证协商和更新包安全校验。
- 恢复服务端请求客户端局域网地址、客户端断线重连和心跳退出处理。
- 兼容客户端配置别名 `server`/`server_addr`、`tp`/`conn_type`。

### Web 管理面板

- 默认语言为简体中文，登录页和管理页支持中英文切换。
- 修复 Bootstrap 下拉菜单缺少 Popper.js 导致语言菜单无法打开的问题。
- 管理面板升级为基于 ZUI 3 的运维控制台：统一导航、面板、表格、表单说明、状态与空数据反馈，支持浅色/深色主题、响应式布局和键盘可访问交互。
- 补齐加载、空数据、错误和表单反馈状态，动态详情内容统一转义。

### 运行时可靠性与安全

- 客户端连接数配额使用原子预留，流量统计提供一致快照；HTTP、UDP、WebSocket 代理加强并发关闭和资源回收。
- 发布模板不再携带固定弱凭据；首次启动会轮换已知占位值，配置和日志文件权限按最小权限创建。
- 随机凭据使用系统 CSPRNG，IP 白名单授权接口限制为同源访问，日志不再输出授权密码或客户端密钥。
- 当整个 `users.json` 在升级时缺失，会从仍保留旧凭据的历史客户端恢复对应用户；已存在文件中的删除、停用或到期状态仍严格生效。

## v1.1.2 (2026-06-23)

### 隧道表单

- 修复新增和编辑隧道时不同类型字段显示不稳定的问题。
- 隧道表单按 TCP/UDP、HTTP 代理/SOCKS5、私密代理/P2P 和文件访问类型展示相应目标、监听、密钥及目录字段。
- Web 模板启动时会从嵌入资源同步覆盖，避免部署后继续读取旧模板。

### Docker 构建

- 新增 `.dockerignore`，显著减少构建上下文。
- Dockerfile 使用 Go module 缓存和 BuildKit cache mount。

## v1.1.1 (2026-06-15)

### 用户体系

- 新增独立 `User` 模型，用户数据保存到 `conf/users.json`。
- 管理员可创建普通用户，并将多个客户端分配给同一个用户。
- 普通用户登录后可查看和管理自己名下多个客户端。
- 普通用户权限按客户端归属过滤，不能访问用户管理和全局设置。

### 配额和到期

- 新增用户级最大隧道数限制。
- 普通隧道和 Host 域名规则统一计入客户端级和用户级配额。
- 用户到期后自动停用，并断开/清理名下客户端运行资源。

### 兼容迁移

- 启动时自动将旧客户端 `WebUserName` / `WebPassword` 迁移为普通用户。
- 同名同密码合并；同名不同密码自动生成 `用户名_客户端ID`。
- 保留旧客户端登录兼容，降低升级风险。

### CI/CD

- 修复 GUI 前端 `package.json` BOM 导致的 Yarn 安装失败。
- GUI 构建统一使用 Yarn 1.22.22。
