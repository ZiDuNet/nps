# NPS 1.1.45 升级说明

本版修复登录、审计页面及用户用量趋势，并增加邮箱找回密码和管理员日志清理。
Bridge 握手、NPC 业务协议、历史快捷命令和业务 JSON 格式不变，旧 NPC 无需同步升级。

## 登录与找回密码

- 独立用户可使用原用户名或绑定邮箱加密码登录；邮箱不区分大小写，精确用户名优先。重复的历史邮箱不会随机匹配账号。
- `allow_user_vkey_login` 只控制旧客户端面板登录。关闭后，旧客户端登录、旧客户端网页会话和免登恢复都会被禁止；独立用户、管理员和 NPC Bridge 连接不受该开关影响。
- 开关打开时，可使用 `user`、历史客户端面板用户名或所属用户的用户名/邮箱搭配对应 VKey 登录，但只能访问这个客户端。
- 只有 `allow_user_register=true` 时才开放“找回密码”。请在“全局参数 → 用户注册”配置可用 SMTP；无需同时开启注册邮件验证，但用户必须有唯一、有效的绑定邮箱。管理员账号、未绑定邮箱的账号和客户端 VKey 不走此流程。
- 找回验证码与注册验证码相互隔离，10 分钟有效、一次使用，发送有冷却和限频，输错 5 次作废；邮件异步发送，接口不公开邮箱对应账号是否存在。
- 成功重置后，该用户的旧网页会话与 3 天免登凭证失效，API Token、VKey、限额和业务配置不变。升级本身不会批量注销用户。

## 审计与连接日志

首次从其他页面打开“审计与连接”不再卡在加载状态。页面只从所选当前日志文件尾部
读取最近最多 2000 条，再按权限、筛选和分页展示；普通用户仍只能查看属于自己的记录。
搜索不会读取更早历史，既有 `/api/v1` 审计查询范围保持不变。

管理员可在当前日志 Tab 选择保留天数并手动清理。此操作**不可恢复，请先备份**；
仅清理所选当前操作审计或连接 JSONL 文件，不处理 `nps.log`、外部轮转归档或用量历史。
未知、损坏和不完整记录保留，文件权限及清理时追加的记录受到保护。

独立审计/连接文件没有新增自动轮转；`log_max_size`、`log_max_files`、`log_max_days`
仍只控制运行日志，生产环境继续安排外部归档和磁盘监控。
Docker 路径及目录权限参考 [1.1.44 升级说明](upgrade-1.1.44.md)。

## 用量趋势与历史清理

- 修复用户/客户端采样缺少自身范围标识，旧 `usage_history.json` 在加载时兼容补齐，不推测历史资源归属，不改变查询权限。保留期内的历史不用删除重建。
- 新启动采集需要经过一个采样周期才能产生第一个点。只有经过 NPS 代理的用量计入，P2P 直连不计入。
- 启动和每次采样自动删除保留期之外的数据点；默认分钟精度保留 48 小时、五分钟精度保留 90 天，分别由 `usage_history_1m_hours`、`usage_history_5m_days` 控制。
- 已删除资源在两种精度历史均过期后自动回收空记录和基线；仍配置的离线资源保留累计量，不会因没有新流量被提前删除。过期历史不再恢复。
- 清理后的内存数据在后续写盘时持久化，写盘间隔由 `usage_history_save_every` 控制，正常退出仍额外保存；并发保存已串行化。

## 升级步骤

1. 备份完整 `conf`、业务 JSON、证书、`instance.key`、`web_sessions.json`、用量历史及独立日志；自定义日志/历史目录需要单独备份。
2. 替换 NPS 二进制或更新 Docker 镜像，保留原挂载目录和配置后重启，不需要批量更新 NPC。
3. 浏览器强制刷新，检查用户名/邮箱登录、VKey 登录权限、首次审计加载和仪表盘趋势。使用说明嵌入窗口会自动适配可用区域。
4. 需要邮件找回时，先确认注册开关及 SMTP 可用；需要清理日志时，确认已备份并核对当前 Tab 与保留天数。

回滚前停止服务，再恢复旧二进制；如需恢复已过期或手动清理的数据，必须从备份恢复。
账号密码重置及旧凭证撤销不会因回滚自动撤销。
