# 介绍

NPS 是一款轻量级、高性能、功能强大的内网穿透代理服务器，配备现代化 Web 管理面板。

## 功能亮点

- **Web 管理** — 可视化配置和管理 TCP/UDP 隧道、域名代理、HTTP/SOCKS5 代理等
- **实时监控** — 流量统计、带宽监控、客户端状态实时展示
- **明暗主题** — Web 面板支持一键切换明暗主题
- **多协议支持** — TCP、UDP、HTTP(S)、SOCKS5、P2P、Secret、文件访问
- **安全增强** — TLS 加密、IP 白名单/黑名单、流量/带宽限制、验证码保护
