# API 兼容入口

API 文档已拆分为三个公开入口：

- [对外 API v1](api.md)：推荐新集成使用。覆盖完整 `/api/v1` 端点、管理员签名、普通用户 Token、统一响应信封、JSON 请求体与分页。
- [API 鉴权与兼容](extend/api.md)：签名、时间戳、加密 `auth_key`、管理员与普通用户凭据边界。
- [历史 Web API](extend/webapi.md)：客户端、用户、隧道、域名和全局参数的历史路径与兼容约定。

新系统集成请使用 `/api/v1`；已经依赖旧 `/auth/*`、`/client/*`、`/index/*`、`/user/*` 或 `/global/*` 的调用可以继续使用，升级 1.1.37 不需要修改。旧链接保留用于兼容外部引用。
