# 飞牛 fnOS 原生 NPC 包

NPC 提供仅客户端的 fnOS 原生 FPK 包。它不监听任何网络端口，也不提供公网 Web 入口；配置页面通过飞牛统一网关挂在 `/app/NPC-Pro`，后端只监听本地 Unix Socket，并复用飞牛登录态。

## 内嵌设置页

安装后在飞牛桌面打开 **NPC-Pro**，会进入内嵌设置页。页面提供：

- 连接列表：查看每一条连接的备注、服务端地址、协议和启用状态。
- 新增 / 编辑连接：选择「快捷指令」时只显示快捷码输入框；选择「手动填写」时才显示域名、端口、VKey、协议，并按协议联动显示 WS/WSS 路径、QUIC ALPN、TLS ServerName、证书指纹和 CA 文件。
- 直接编辑 `npc.conf`：每条连接都能打开原始配置文本编辑器，改动会先校验再原子写入。
- 运行日志：查看最近最多 500 条日志，并支持一键清空。

保存后运行中的 NPC 会热重载，不需要重启应用。飞牛网关会在转发前校验用户会话，页面不会回显 VKey 或快捷码。

## 配置文件

首次安装时，应用会在飞牛应用的 `etc` 配置目录释放完整的 `npc.conf`。文件来自项目的配置模板，包含所有常用字段、TLS、代理、限额、P2P、Secret、隧道、域名和健康检查示例；示例规则默认全部注释，不会自动开放端口。

同时会保留 `npc.conf.example` 作为参考。实际文件可以直接用文本编辑器修改，字段以当前版本 [NPC 配置文件参考](config-file.md) 为准。

重要规则：

- `npc.conf` 是实际运行配置，原生应用设置和手动编辑使用同一份文件，不存在第二套隐藏 JSON 配置。
- 修改保存后，运行中的 NPC 每秒检查配置；文件完成写入并连续两次读取有效后才应用，编辑器的临时空文件不会立即断开连接。
- 配置无效时保留旧连接并记录错误，不会用模板覆盖或清空旧文件。
- 配置文件含 VKey、密码和代理凭据，应用自动使用 `0600` 权限；不要把该文件上传或提交到公共仓库。
- 升级 FPK 时保留 `etc` 目录中的 `npc.conf`、手写规则和注释，不会用新模板覆盖。

## 多个 VKey

一个 `npc.conf` 对应一个服务端入口和一个 VKey。需要在同一台飞牛连接多个不同 VKey 时，在原生设置中新增连接，应用会为其他连接创建独立目录和文件：

```text
etc/npc.conf
etc/connections/<连接编号>/npc.conf
```

每个文件由独立 NPC 子进程运行，因此停用、修改或服务端删除其中一条连接，不会停止其他 VKey。连接文件中的隧道或域名规则仍使用原有 NPC 配置模式；此时服务端必须允许配置连接，否则只应保留 `[common]` 连接参数。

快捷启动码和手动填写是二选一。快捷码会转换为完整的 `[common]`，手动设置只更新连接字段；其它字段、规则节和注释继续保留。

## 日志

运行日志位于应用 `var` 数据目录的 `npc.log`，按 5 MiB 轮转并保留 3 个备份，权限为 `0600`。日志条目带连接编号和协议，移除了终端颜色控制符，并遮盖 VKey、密码、Token、Secret 和代理凭据。

内嵌设置页可查看最近最多 500 条日志（不超过 128 KiB）。清空操作会清理当前日志和三个轮转文件，不能恢复；日志预览不是实时流，点击刷新即可更新。

## 更新与限制

飞牛 FPK 和 Docker 客户端不接受服务端远程自更新。请从应用中心安装新版 FPK；配置文件和 `etc` 数据会保留。普通 CLI、系统服务和 GUI 的既有更新行为不受影响。

FPK 构建成功不等于真机兼容性完成。首次发布前必须在实际 fnOS 设备上验证：安装向导、内嵌设置页的网关访问与登录态、表单联动、直接编辑 `npc.conf`、多 VKey 启停、升级保留配置和日志清理。
