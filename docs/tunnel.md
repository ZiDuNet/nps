# 隧道模式

## 模式总览

| 模式 | 协议 | 典型场景 | 需要公网端口 |
|------|------|---------|------------|
| TCP 隧道 | TCP | SSH、远程桌面、数据库 | 是 |
| UDP 隧道 | UDP | DNS、游戏、内网 UDP 服务 | 是 |
| HTTP(S) 反向代理 | HTTP/HTTPS | 微信开发、小程序、Web 站点 | 否（基于域名） |
| HTTP 正向代理 | HTTP | 通过代理访问内网站点 | 是 |
| SOCKS5 代理 | SOCKS5 | 内网资源全面访问 | 是 |
| P2P 穿透 | P2P/UDP | 直连内网设备，不经服务器 | 否 |
| 私密代理 | TCP | 安全的临时连接 | 否 |
| 文件访问 | HTTP | 浏览本地文件 | 是 |

## TCP 隧道

将公网服务器的某个端口映射到内网机器的端口。

**场景：** 通过公网服务器 1.1.1.1 的 8001 端口 SSH 连接内网 10.1.50.101

```
# Web 面板添加：模式=TCP，服务端端口=8001，内网目标=10.1.50.101:22
ssh -p 8001 root@1.1.1.1
```

支持负载均衡：内网目标填写多个地址（逗号分隔），自动轮询。

## UDP 隧道

与 TCP 类似，转发 UDP 流量。

**场景：** 使用内网 DNS 服务器 10.1.50.102

```
# Web 面板添加：模式=UDP，服务端端口=53，内网目标=10.1.50.102:53
# 然后将 DNS 地址设为 1.1.1.1
```

## HTTP(S) 反向代理

基于域名的 HTTP/HTTPS 反向代理，多个域名共用 80/443 端口。

**场景：** `a.proxy.com` → `127.0.0.1:81`，`b.proxy.com` → `127.0.0.1:82`

1. 将 `*.proxy.com` 解析到公网服务器
2. Web 面板添加域名规则：`a.proxy.com` → `127.0.0.1:81`
3. 添加域名规则：`b.proxy.com` → `127.0.0.1:82`

支持特性：
- 自动 HTTPS（HTTP 301 跳转）
- 自定义 Header、Host 修改
- URL 路由（同一域名不同路径转发到不同目标）
- 泛解析（`*.proxy.com`）
- 自定义 404 页面
- HTTPS 证书上传或指定路径
- 站点保护（用户名/密码）

## HTTP 正向代理

在公网开放一个 HTTP 代理端口，通过该代理访问内网站点。

```
# Web 面板添加：模式=HTTP代理，服务端端口=8004
# 浏览器设置 HTTP 代理为 1.1.1.1:8004
```

## SOCKS5 代理

在公网开放 SOCKS5 代理端口，可访问内网任意设备。

```
# Web 面板添加：模式=SOCKS5，服务端端口=8003
# 使用代理工具（如 Proxifier）连接 1.1.1.1:8003
```

## P2P 穿透

点对点直连，流量不经过服务器。穿透成功率取决于双方 NAT 类型。

前提：在 `nps.conf` 中配置 `p2p_ip` 和 `p2p_port`

**步骤：**
1. Web 面板添加 P2P 隧道，设置唯一密钥（如 `p2pssh`）
2. 访问端执行：

```bash
./npc -server=1.1.1.1:8024 -vkey=key -password=p2pssh -target=10.2.50.2:22
# 默认本地端口 2000
ssh -p 2000 root@127.0.0.1
```

NAT 类型检测：
```bash
./npc nat -stun_addr=stun.stunprotocol.org:3478
```

## 私密代理

无需占用公网端口，通过密钥直接建立安全连接。

**步骤：**
1. Web 面板添加私密代理，设置密钥（如 `secrettest`）和内网目标
2. 访问端执行：

```bash
./npc -server=1.1.1.1:8024 -vkey=key -password=secrettest -local_type=secret
# 默认本地端口 2000
```

## 文件访问

将本地目录通过 HTTP 暴露到公网。仅支持配置文件模式。

```ini
[file]
mode=file
server_port=9100
local_path=/tmp/
strip_pre=/web/
```

访问 `http://ip:9100/web/` 相当于浏览 `/tmp/` 目录。
