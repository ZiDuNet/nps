# NPS 1.1.39 本地升级说明

> 本文对应列表身份信息、筛选联动、隧道目标展示和域名访问入口优化版本。
> 正式发布状态以 `lib/version.VERSION`、GitHub Release 标签和发布流水线结果为准。

## 功能变化

- 用户管理列表改为用户名主行、备注次行显示，并保留账号状态和资源配额信息。
- 客户端列表的备注和所属用户改为居中双行展示，超长内容单行省略并可悬浮查看全文。
- 客户端列表默认显示入口和出口流量，并在表头标明「公网→内网」和
  「内网→公网」方向。
- 管理员用户和客户端筛选统一使用「备注（账号）」和「客户端备注（ID）」；
  隧道和域名反代选择所属用户后，客户端选项会联动收窄，也可单独筛选客户端。
- 域名反代增加平台或自定义来源标签，HTTP/HTTPS 入口改为带外链图标的明确按钮。
- 隧道目标按主机和端口分行展示，只有端口时保持单行；访问地址提供复制按钮，
  TCP 隧道额外提供 HTTP 尝试入口。
- TCP 当前连接数默认收起，可通过列设置恢复，展开详情仍可查看。

## 配置与数据迁移

本版本不新增必填配置，不改变 `nps.conf` 字段语义，也不需要迁移 JSON 数据。
升级时保留现有 `nps.conf`、`clients.json`、`tasks.json`、`hosts.json`、
`users.json`、证书和日志文件。

## 升级步骤

1. 备份整个 `conf` 目录。
2. 停止 NPS。
3. 替换 NPS 程序并保留原 `conf` 目录。
4. 启动 NPS 并登录管理面板。
5. 检查用户管理、客户端、TCP/UDP 等隧道和域名反代列表的显示与筛选。
6. 浏览器如保留旧静态资源，强制刷新一次页面。

## 版本兼容

| 组件 | 兼容范围 |
|------|----------|
| NPS `1.1.39` + NPC `1.1.38` | 完全兼容 |
| NPS `1.1.39` + NPC `1.1.28` 及以下 | 继续使用历史 Bridge 握手和既有 TCP/KCP 连接方式 |
| 快捷命令 | v1/v2 格式均不变 |
| Web 与 `/api/v1` | 既有路径、字段和响应信封不变 |

NPS 与 NPC 不需要同步升级。本版本的能力集中在服务端 Web 展示和列表交互，
不会强制断开已有客户端。

## 回滚

停止 NPS，替换回 `1.1.38` 程序即可。本版本未修改配置格式和持久化结构，
通常无需恢复数据；回滚前仍建议备份当前 `conf` 目录。
